# ✦ A Little Universe for Neelu ✦
### *An Extraordinary Interactive Birthday Surprise for Neelam • 18 November*

## 🌟 Overview

**"A Little Universe for Neelu"** is a premium, cinematic interactive digital gift created to celebrate Neelam (Neelu) on her special day, **18 November**. 

Far beyond a traditional scrolling card, this website is an interactive universe combining real-time 3D graphics, celestial particle engines, interactive physical gestures, heartfelt storytelling, and a curated museum of memories celebrating her as an irreplaceable best friend and guardian angel.

## 🚀 How to Run the Website

### Option 1: One-Click Launcher (Recommended)
Simply double-click the **`start.bat`** file in the project folder!
- It will automatically launch a local web server.
- It opens the website in your default browser at `http://localhost:8000`.
- It displays your local Wi-Fi IP address so you can open it on your **Android phone** instantly!

### Option 2: Direct Browser Open
Double-click **`index.html`** in Windows Explorer. It will immediately open in Google Chrome, Microsoft Edge, or any modern browser.

### Option 3: View on Android Mobile Browser
1. Make sure your computer and Android phone are on the same Wi-Fi network.
2. Run `start.bat` on your computer.
3. On your Android phone's Chrome browser, enter the URL displayed in the console (e.g. `http://192.168.1.X:8000`).
4. Enjoy full touch swipe gestures, microphone candle blowing, and responsive 3D visuals!

## 🎵 Sound & Music Experience

1. **Background Music Player**:
   - Persistent, visible player widget in the top header with **Play / Pause / Mute** toggle and live animated equalizer bars.
   - Master **Volume Slider** (0% to 100%) and instant mute icon (`🔊`, `🔉`, `🔈`, `🔇`).
   - Autoplay compliant: music smoothly begins playing only **after the user's first touch/click** on the website.
   - Music is completely optional and can be paused or muted at any time.

2. **Custom Music Replacement (`assets/music/`)**:
   - Your background song is placed at `assets/music/bg-music.aac`.
   - To replace it with any song: simply drop your audio file (`bg-music.mp3`, `bg-music.aac`, or `bg-music.wav`) into the `assets/music/` folder!
   - Centralized path configuration in `js/config.js` (`audio.bgMusicPath`).

3. **Subtle Web Audio API Sound Effects (Zero External Dependency)**:
   - **💌 Envelope Opening**: Realistic paper rustle, wax seal snap, and delicate sparkle chime (`soundEngine.playEnvelopeOpen()`).
   - **🔘 Button Clicks**: Gentle, tactile wooden/bubble tick chime on interactive buttons across the site (`soundEngine.playButtonClick()`).
   - **🎂 Birthday Candles Going Out**: Soft breath air whoosh and smoke extinguishing shimmer (`soundEngine.playCandleBlow()`).
   - **🎉 Confetti Explosion**: Party popper pop and ascending celebratory chimes (`soundEngine.playConfettiExplosion()`).
   - **🎆 Final Celebration**: Majestic celebratory chord fanfare and fireworks cascade (`soundEngine.playFinalCelebration()`).

4. **100% Graceful Fallback**:
   - The website continues to function flawlessly even if audio files are offline, blocked, or muted.
   - Includes a built-in generative celestial synthesizer as an ambient fallback.

## 🎨 Customizing Text, Photos & Audio

Everything is centralized in one easy file: **`js/config.js`**!
- **Edit text & letter**: Open `js/config.js` in any text editor and change any paragraph or quote.
- **Photos**: All 20 photos are stored in `assets/photos/` (`photo-01.jpeg` through `photo-20.jpeg`).
- **Video**: Stored in `assets/video/memory-video.mp4`.
- **Audio**: Stored in `assets/audio/voice-or-music.aac`.
